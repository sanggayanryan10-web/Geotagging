    Using Geotag Studio

    1. Upload a photo (drag it in or use the button).
    2. Enter details by typing, by clicking the map, or by reading the photo’s own EXIF data. Badges show each value’s source.
    3. Pick a template, then adjust corner, colors, text and map thumbnail. Drag the overlay to fine-tune.
    4. Compare with Before / After, then Export a JPG or PNG.

    Good to know

    • Everything is processed in your browser. Photos are not uploaded and nothing is saved unless you tick “Remember the key”.
    • The overlay shows what you entered. It is not verified or authenticated GPS evidence, and the app never adds a “verified” badge.
    • The exported file is an edited copy. Canvas export does not carry over the original EXIF data (camera info, original GPS, timestamps) and this app does not write new EXIF.
    • Map search, address lookup and map thumbnails contact Google and may incur charges on your API key.
    • Please use the tool only for honest documentation. Do not use it to misrepresent where or when a photo was taken.
